# Se7en Wiki

Durable technical knowledge for Se7en.

This is not a diary and not raw chat history. It is the curated knowledge base: project notes, patterns, mistakes, concepts, and maintainer observations that should survive across sessions.

## Structure

```text
projects/      repo-specific field notes
patterns/      reusable engineering patterns
mistakes/      mistakes and prevention notes
concepts/      technical concept explanations
maintainers/   maintainer and project-community preferences
```

## Writeback Rule

After meaningful technical work, ask:

- What did I learn that should be reusable?
- Which project note should be updated?
- Did I hit a mistake that should not repeat?
- Is there a pattern worth naming?

If yes, write it here.

Every task should run a writeback review before completion. See [`patterns/agent-writeback-review.md`](patterns/agent-writeback-review.md).

## Privacy

Keep this public-safe. Do not include secrets, private endpoints, credentials, private conversations, or personal information.
